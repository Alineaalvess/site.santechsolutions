# Santech Solutions — experiência 3D

Abra `index.html` no navegador (funciona offline, sem bibliotecas). Para publicar, envie a pasta inteira.

- `js/engine.js` — cena 3D em canvas (corredor, túnel neon, cidade, aurora, cosmos, warp). Cores por seção: objeto `SEC` em `js/main.js` (campo `c`).
- `js/main.js` — navegação, textos e cores das seções (objeto `SEC`). `js/audio.js` — trilha ambiente espacial gerada por código (botão de som no canto superior direito).
